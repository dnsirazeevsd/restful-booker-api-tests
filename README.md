# Тестовое задание: Restful Booker API

## Что внутри:
- **Postman Collection**: Набор запросов с автотестами во вкладке Tests. Коллекция использует переменные для токена и ID бронирования.
- **Test Cases**: Таблица с позитивными и негативными сценариями.
- **Bug Reports**: Описание найденных несоответствий в работе API.

## Найденные баги:
- **BUG-001** — API возвращает 200 OK при неверном пароле, пустом теле и отсутствии password (вместо 401/400).
- **BUG-002** — при создании брони с неполными данными сервер падает с 500 вместо 400.
- **BUG-003** — фильтрация броней по невалидной дате (`GET /booking?checkin=invalid-date`) тоже отдает 500 вместо 400.
- **BUG-004** — удаление брони возвращает 201 Created вместо ожидаемого 204/200.
- **BUG-005** — `/ping` (health check) возвращает 201 вместо 200.
- **BUG-006** — при создании брони формат даты checkin вообще не валидируется, сервер молча создает бронь даже с датой в неправильном формате (DD-MM-YYYY).
